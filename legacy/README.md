# Retained historical material

These scripts and artifacts preserve work that is outside the supported experiment/analysis workflow. Some still contain original hardcoded paths, old input conventions or configuration values. They are retained for inspection and comparison, not exposed as current commands.

Use the repository root README for supported commands. `docs/migration_manifest.json` maps original locations to retained files. The presence of a script here does not mean its scientific content is obsolete; differing implementations need review before retirement.
