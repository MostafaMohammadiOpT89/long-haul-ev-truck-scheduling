# Paper instance set (n = 43)

The paper comparison uses the 43 tests listed in `instances/PAPER_INSTANCE_SET_43.txt`
and `reviewer_results/01_instances/PAPER_INSTANCE_SET_43.txt`.

- `short_cl2_cu2_Balanced`
- `short_cl2_cu2_Unbalanced`

Those two have no Full/Partial labeling runs in the saved base-scenario bundle. The paper
set is 13 short + 15 medium + 15 long.
