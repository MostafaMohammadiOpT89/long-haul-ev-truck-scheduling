# Current paper analysis

The illustrative driver schedule in the problem definition is generated by
`python -m analysis.driver_schedule` from the repository root. Edit the activity
durations (in minutes) in `analysis/driver_schedule.py`. The script writes the
publication PDF and PNG preview to `manuscript/synch_paper_latex/figures/driver_schedule.*`.

Run from the repository root:

```sh
python -m analysis.conditions.run
python -m analysis.conditions.audit
```

`conditions/run.py` is the single figure/table generator. `data.py` validates
paired results and selects fixed matched cohorts; `plot_helpers.py` contains
shared rendering helpers. No figure number is part of an export filename.

```text
analysis/conditions/
    run.py, data.py, plot_helpers.py, operations.py, audit.py
    figures/
        time_penalty.pdf / .png
        extra_time.pdf / .png
        battery.pdf / .png
        power.pdf / .png
        spacing.pdf / .png
        consumption.pdf / .png
        penalty_parts.pdf / .png
        charge_split.pdf / .png
        rest_overlap.pdf / .png
        early_charge.pdf / .png
        extra_breaks.pdf / .png
    tables/             # base_case.tex/.csv, sensitivity.csv, matched data, coverage.json
    latex/              # base_comparison.tex, sensitivities.tex, packages.tex, preview.tex
    previews/           # combined previews for review, not manuscript panels
    audit.json          # source hashes, cohort IDs, common vertical scale
    conditions.zip      # Overleaf-ready PDFs, table, and LaTeX snippets
```

The sensitivity plots use grouped bars by route class, class means and IQR,
and the same vertical limits/ticks across all four panels. The common upper
limit is chosen from all displayed means and IQR endpoints, so new data cannot
silently exceed the plotting range. The current scale is 0--5%.

The base configuration is 750 kWh, 350 kW, 60 km and 1.49 kWh/km. The base
comparison uses all 43 paper instances. Sensitivities use the same matched
instances at every available setting within a panel; cohorts can differ
between panels. Missing classes and battery settings are not treated as zero.

`operations.py` explains the base-case penalties for all 43 pairs. It joins
selected observations in `output/runs/details.jsonl`, reconciles the duration
decomposition, and validates battery-energy balance along the saved minimum-time
path. `penalty_parts` separates uncovered charging from additional breaks.
`charge_split` shows pooled energy and stop-count shares during breaks, during
daily rests, and outside either. At constant power, energy shares equal physical
charging-time shares. The three schedule examples use a common time axis.
Charging occupies most of the activity-bar height, with dark teal fill and
diagonal hatching; horizontal extent remains the physical charging duration.
`tables/penalty_summary.tex` is a compact class-level alternative to the
per-instance decomposition figure; both remain available for review.
`latex/operational_paragraph.tex` contains the manually editable Section 5.1
draft with its table and all three figure environments integrated. Copy this
single block into Overleaf and upload the referenced PDFs to `figures/conditions/`.
The existing `preview.tex` wraps this block for the editor's compilation.
The generator packages the integrated draft without overwriting it.
Charging during rest is placed at the end of the rest for display only; the
saved records do not determine its unique placement within the rest. Diesel
proxy charging bookkeeping is omitted. The audit and source-row choices are
saved in `operations_audit.json`, with numeric tables under `tables/`.

Inputs come from `output/runs/summary.csv`. Full raw observations remain in
`output/runs/details.jsonl`; `summary_all.csv` retains out-of-scope settings.
`EV_TRUCK_ANALYSIS_OUTPUT` can redirect generated outputs without moving code.

Run `python -m analysis.instance_visualization --paper` to regenerate the three
representative route panels, their shared marker legend, and the single-page
`benchmark_routes.pdf` and PNG preview in `manuscript/synch_paper_latex/figures/`.
The overview uses `instances/PAPER_INSTANCE_SET_43.txt`, cumulative distances
from the benchmark matrices, and a 60 km station grid. Each route class has its
own kilometre scale. The command without `--paper` exports individual benchmark
plots and the six-route overview. Shared input/provenance utilities
and their source manifests remain under `common/` and `configs/`.

Superseded analysis scripts, duplicate generated results, and rejected plot
alternatives were removed at the user's request. `docs/analysis_cleanup.json`
records paths, checksums and the local recovery archive. Raw experiment data,
model code, datasets and manuscript-linked assets were preserved.
